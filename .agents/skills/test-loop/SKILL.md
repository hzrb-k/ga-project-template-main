# テスト 差し戻しループの進め方（C11 / B・M・T・I・E 分類）

承認済みテスト仕様書を起点に、生成役（`test-to-code`）と実行役（`test-runner`・読み取り専用）を責務分離したまま、全テスト通過または人間確認待ちまで進める正本スキルです。

## 前提：責務分離（崩さない）
- **生成役 = `test-to-code`**: C11 テストコード（`tests/test_*.c`）と `CMakeLists.txt` テスト登録を作成・修正する。ビルド・実行はしない。
- **実行役 = `test-runner`**: `cmake --build build` および `ctest --test-dir build --output-on-failure --timeout 10` を実行し、失敗原因を **B / M / T / I / E** へ切り分けて報告する。ファイル編集権限を一切持たない。
- **メイン（あなた＝オーケストレータ）**: `invoke_subagent` で両者を仲介し、分類結果に応じて次の一手を決める。

> 期待値（`CHECK`）を実挙動へ書き換えてテストを通すことは本物のバグ（`I`）やメモリ破壊（`M`）を隠蔽する最悪のアンチパターンであり、厳禁です。

## 入力（起動時に確定）
1. **テストレベル**: `unit` / `integration` / `system`
2. **実行手段**: 既定 `ctest`（対応する実装プロファイル `.agents/skills/ctest-conventions/SKILL.md` を参照）
3. **対象仕様書**: 承認済みの `docs/tests/{unit|integration|system}/<名前>.md`（未承認なら人間承認を待つ）

## 起動の流れ
1. **入力・環境確認**: 仕様書が承認済みか、およびホストに `cmake` / `ctest` / Cコンパイラが存在するか確認する。ツールチェーン未導入の場合は `E` として人間へ報告し、テストコード生成のみ先行するか確認する。
2. **テストコード生成**: `invoke_subagent` で `TypeName: "test-to-code"` を起動し、テストレベル・実行手段（`ctest`）・対象仕様書パスを渡す（`manual` ケースは対象外）。
3. **ビルド＆実行**: `invoke_subagent` で `TypeName: "test-runner"` を起動し、テストレベル・実行手段・対象テストを渡して報告を受け取る。
4. **原因分類と差し戻し振り分け**: 下記表に従って次の一手を実行する。
5. 全 PASS または停止条件に達するまで 2〜4 を繰り返す。

## 差し戻しの振り分け（B / M / T / I / E）

| 分類 | 意味 | 次の一手 |
|---|---|---|
| **B（Build）** | コンパイルエラー・警告エラー（`-Werror` / `/WX`）・リンクエラー | ・テスト側起因 → `test-to-code` へ差し戻し<br>・本体/ヘッダ/`CMakeLists.txt` 起因 → メインで修正して再実行（最大3周） |
| **M（Memory / UB）** | ASan/UBSan 検知、クラッシュ、`cppcheck` 検知 | ・テスト側起因 → `test-to-code` へ差し戻し<br>・本体起因 → メインでポインタ・境界・解放漏れを修正し、`c-reviewer` 再確認後に再実行（最大3周） |
| **T（Test）** | テストコードの組み立て・前提・比較不備 | `test-to-code` へ差し戻して修正 → 再実行（最大3周） |
| **I（Implementation）** | 仕様書の期待と実装の挙動が不一致（実装バグ疑い） | **テストを改変せず人間へ報告して停止**（修正方針の承認後に実装修正） |
| **E（Environment）** | ツールチェーン未導入・CMake 環境依存エラー | **人間へ報告して停止** |

## 上限・停止条件
- `T`（およびテスト側 `B`/`M`）の差し戻しは **最大 3 周**。3 周しても解消しない場合は `I` または設計不整合を疑い、人間へ上げて停止する。
- `I`・`E` が 1 件でも出たら、その時点で自動ループを止めて人間へ報告する。
- テスト結果（合否）は `docs/tests/*.md` へ書き戻さない。

## 各ターンでユーザーへ返す内容
- PASS / FAIL サマリ、テストレベル、実行手段、周回数
- 失敗ケースの B/M/T/I/E 内訳と差し戻し先
- 停止時（`I`/`E` または上限到達）は具体的なログ抜粋と人間に判断してほしい点
